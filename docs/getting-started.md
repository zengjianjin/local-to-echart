# 使用指南

本文面向第一次使用 Local to ECharts Studio 的用户，按“启动 → 导入 → 编辑 → 导出”的顺序说明。

## 1. 环境要求

- Node.js 20 或更高版本
- pnpm

## 2. 启动

```bash
pnpm install
pnpm dev
```

浏览器开发服务默认运行在 `http://localhost:1420`。

桌面版开发模式：

```bash
pnpm dev:electron
```

该命令会启动开发服务（端口 `1422`）并通过 `VLE_DEV_URL` 传给 Electron 主进程。

生产构建与打包：

```bash
pnpm typecheck
pnpm build
pnpm dist
```

`pnpm build` 只生成前端静态文件到 `dist/`；`pnpm dist` 会调用 electron-builder 生成安装包。也可使用 `pnpm preview` 本地预览构建产物，或用 `pnpm electron` 直接以 Electron 加载已构建的 `dist/`。

## 3. 界面总览

应用分为三栏：

| 区域 | 作用 |
| --- | --- |
| 左侧「数据源」 | 导入文件、加载示例数据、数据节点操作、数据速览 |
| 中间「图表预览」 | 实时渲染 ECharts 图表，顶部工具栏负责导入/导出配置与图片 |
| 右侧「图表设置」 | 表单编辑与 JSON 编辑双模式，可切换浅色/深色外观 |

## 4. 导入数据

1. 在左侧「数据源」区域拖放 `.csv` / `.tsv` / `.txt` / `.xlsx` / `.xlsm` / `.xls` 文件，或点击「选择文件」。
2. Excel 文件包含多个工作表时，会弹出工作表选择框，列出每个表名与行数；选中后点「载入工作表」或双击表名即可导入。只有一个工作表时直接导入。
3. 想快速体验可点击「示例数据」，会载入内置的 12 个月销售数据。
4. 文件解析完全在浏览器本地完成，不会上传。

`examples/sample.csv` 可直接拖入验证。

### 数据速览与全量预览

左侧表格默认只显示**前 12 行、前 5 列**，表头下方带字段类型标记（`#` 数字、`T` 文本、`B` 布尔、`D` 日期）。

点击标题栏的「全量」或表格底部的「查看全部 N 行」，会打开全量预览弹窗：

- 显示所有列与所有行，表头和行号在滚动时固定
- 顶部输入框可按任意单元格内容搜索
- 先渲染 500 行，向下滚动自动加载更多
- 按 `Esc`、点击右上角关闭按钮或点击弹窗外空白区域均可关闭

### 数据节点操作

左侧「数据节点」区域提供：

- 「重新生成」：用当前表格覆盖 `dataset[0].source` 并重建 `series`
- 「清空」：移除当前数据与系列
- 「快速添加数值系列」：选择一个数值列，一键追加对应的 `series`

## 5. 编辑图表配置

右侧「图表设置」顶部可在「表单编辑」和「JSON 编辑」间切换，两者共享同一份 option。

### 分区导航

分区按「基础 / 布局 / 系列 / 扩展」四组常驻显示，无需横向滚动。顶部「快捷」行可一键跳转到标题、图例、网格、X 轴和系列；右侧的「网格线 开/关」按钮可一次切换 X/Y 轴的分隔线。

搜索框支持字段名、路径和中文标签，输入后会过滤到匹配分区。

### 表单编辑要点

- 每个字段占两行：标签 + 控件。鼠标停在标签上可看到完整路径和说明。
- 未设置的字段显示占位提示，开关为**虚线圆点居中**的“默认”态；此时点击开关会写入 `false` 并立即反映到图表。
- 已设置的字段，标签旁会出现「恢复默认」小图标，点击后删除该字段，让 ECharts 使用自己的默认值。
- 新增数组项时只写入必要的默认值，例如新 series 只有 `type: 'bar'`，不会塞入会改变图表行为的 `z: 0` 或 `legendHoverLink: false`。
- `series` 的字段会按当前项的 `type` 自动过滤；饼图使用 `encode.itemName` / `encode.value`，柱线图使用 `encode.x` / `encode.y`。
- 结构化输入支持直接粘贴 `["#4F8CFF", "#22C55E"]`、`[50%, 50%]`、`[0, 1]` 等，编辑器会写成数组而不是字符串。

### JSON 编辑要点

- 合法 JSON 会在 250ms 防抖后应用到图表。
- 非法 JSON 只保留在草稿区，不会污染当前配置。
- schema 未覆盖的字段可在 JSON 中添加，切换回表单后会出现在「未知字段」分区，且不会被表单编辑清理。

更多字段细节见 [option-editor.md](./option-editor.md)。

## 6. 导出

中间图表预览顶部工具栏提供以下按钮：

### 图片导出

先选择分辨率，再点击 PNG / SVG / PDF：

- 跟随预览（默认，PNG/PDF 为 2 倍像素）
- 1920 × 1080
- 2560 × 1440
- 3840 × 2160
- 自定义：输入宽高（64–8192）

PNG 与 PDF 按目标像素输出；SVG 是矢量格式，使用相同尺寸作为 viewBox。无论当前界面是浅色还是深色，图片导出**统一使用深色背景 `#0F172A`**。

### 配置导出与导入

- 「项目配置」：导出完整项目 JSON，包含 option 与当前表格数据。
- 「仅 Option」：只导出配置，不含表格；再次导入时需要重新导入数据文件。
- 「导入配置」：选择此前导出的项目配置 JSON 恢复工作区。

项目文件使用 `formatVersion: 1`，旧格式会被明确拒绝。

## 7. 主题切换

右上角有太阳/月亮图标按钮，可在浅色（默认）与深色外观之间切换。选择会写入本地存储，刷新后保留。主题只影响编辑器界面，不影响图表导出配色。

## 8. 常见问题

**图表没有网格线？**
网格线由 X/Y 轴的 `splitLine.show` 控制，可用快捷行的「网格线」按钮一键打开；「网格」分区的 `grid.show` 遵循 ECharts 原生语义，只控制坐标系底纹和边框。

**切换饼图后图例和标题重叠？**
从柱图切换为饼图时，编辑器会自动把 `encode` 转换为 `itemName`/`value`，并将图例调整为滚动模式、下移到 `top: 44`。

**为什么某些字段显示"默认（未设置）"？**
这表示该字段没有显式写入 option，最终效果由 ECharts 自身默认值决定。表单刻意不伪造默认值，以保证表单、JSON 和渲染三方一致。

**数据预览为什么只显示 12 行？**
侧栏是速览；点击「全量」可打开显示所有数据的弹窗。
