# 验收清单

## 自动验证结果

- `pnpm typecheck`：通过。
- `pnpm build`：通过，Vite 5 生产构建成功。
- `node scripts/dev-electron.mjs`：Electron 开发模式启动成功，检测到 Electron 主进程与渲染进程；验证后已清理进程。
- 浏览器冒烟：示例数据加载后生成 `dataset.source` 与默认 `series.encode`，柱状图正确渲染。
- 双模式同步：表单修改 `title.text` 后切换 JSON，能看到更新后的标题。
- JSON 应用：合法 option JSON 应用后，表单分区显示新值。
- 未知字段：JSON 中的未知根字段在未知字段分区可见，表单编辑后字段仍存在。
- 导出：PNG、SVG、PDF 按钮点击后无“图表实例尚未就绪”错误。
- 导出分辨率：工具栏可切换“跟随预览 / 1920×1080 / 2560×1440 / 3840×2160 / 自定义”，PNG 与 PDF 按目标像素输出，SVG 使用相同 viewBox；离屏渲染会关闭动画以避免截到初始帧。
- 深浅主题：默认浅色，右上角太阳/月亮按钮切换深色，选择写入 localStorage 并在刷新后保留；`ink-*` 与半透明 `white/*` 均由 CSS 变量驱动，边框与次要文字在两种主题下均可见。
- 浅色对比度：主按钮/Tab 选中态使用固定纯白色 `text-pure`，开关滑块和选中圆点使用 `bg-pure`；soft 按钮、`primary-100` 与语义色文字按主题切换深浅变体，浅色下不再出现“白底白字”。
- 导出配色：无论当前界面主题，PNG/SVG/PDF 一律使用深色背景 `#0F172A`。
- 数据全量预览：左侧预览只显示前 12 行 5 列，点「全量」或底部「查看全部」打开大弹窗；弹窗显示所有行列、支持单元格搜索、滚动增量加载（每批 500 行）、Esc/点空白关闭。
- JSON 滚动：CodeMirror 滚动容器高度受限于面板，滚动高度大于可视高度，滚动位置可正常改变。
- 展开收起：对象字段分组和数组项折叠标题可正常收起与重新展开。
- 显示网格：`grid.show` 遵循 ECharts 原生语义，只控制直角坐标系底纹与边框；坐标轴分隔线由 X/Y 轴的 `splitLine.show` 单独控制。
- 开关样式：未选中为深色轨道且圆点在左，选中为蓝色轨道且圆点在右；字符串 `false` 不会被误判为开启。
- 布尔三态：未设置时开关为虚线轨道、圆点居中并标注“默认（未设置）”，不再显示为关闭；此时点击直接写入 `false`，图表立即响应；已设置后变为普通二态开关并可“恢复默认”。
- 设置面板布局：分区导航改为「基础 / 布局 / 系列 / 扩展」四组常驻显示，取消横向滚动；新增「快捷」行，一键跳转标题、图例、网格、X 轴、系列，并提供一键切换网格线的快捷按钮。
- 字段紧凑化：字段卡片由 4~5 行压缩为 2 行（标签 + 控件），路径与说明移入悬浮提示，恢复默认改为标签栏小图标；面板加宽到 420px，展开后 560px 并自动切换双列字段布局。
- 数组项操作：上移、下移、复制、删除按钮放在每个子项的标题栏右侧，无需展开或滚动到底部即可操作；点击按钮不会误触折叠。
- 饼图切换：从柱图切换为饼图后，`encode` 自动转换为 `itemName`/`value`，12 个月份显示为 12 个扇区，图例不与标题重叠。
- 表头参数：数据节点默认写入 `sourceHeader: 1`，X 轴从 `1月` 开始而不是把 `月份` 当成数据。
- 多系列：数据节点面板可一键添加数值列系列；点击“订单数”后图表显示销售额与订单数两组柱形，浏览器与全新 Electron 会话控制台均无 ECharts `setOption` 时序错误。
- 默认值显示：未设置的数字/颜色/枚举显示“未设置（默认）”，不再伪造 `0`、`#4F8CFF` 或浏览器默认选中第一项；显式值旁提供“恢复默认”。
- 新增数组项：新增 series 只写入 `type: 'bar'`，新增 dataZoom 写入 `type: 'inside'`、`start: 0`、`end: 100`，不再写入 `legendHoverLink: false`、`z: 0`、`type: ''` 等错误默认值。
- 配置三方一致：饼图 `encode`、`sourceHeader`、图例布局的兼容修正会持久化到 option，表单、JSON 与渲染使用同一份配置。
- 嵌套字段路径：`emphasis.label.show`、`axisLine.lineStyle.color`、`labelLine.lineStyle.color` 等子字段写入正确的 option 路径。

## 手工验收

### 数据导入

- [ ] 选择 CSV 文件，速览表头、类型与前 12 行；点击「全量」打开弹窗查看所有行。
- [ ] 选择 TSV 文件，自动识别制表符分隔。
- [ ] 选择单工作表 XLSX 文件直接导入；选择多工作表 XLSX 文件弹出选择框，显示各表名与行数，双击或点「载入工作表」后按所选表导入。
- [ ] 导入损坏文件，界面显示明确错误且不崩溃。
- [ ] 点击“重新生成”，dataset 节点同步为当前表格。

### 图表编辑

- [ ] 修改 `title.text`、`tooltip.trigger`、`grid.left`，预览即时变化。
- [ ] 在 `series[0].itemStyle.color` 输入颜色，柱形颜色变化。
- [ ] 新增第二个 series，切换为 `line`，图表正确叠加。
- [ ] 调整 series 顺序，图例顺序与绘制层级符合预期。
- [ ] 添加 `dataZoom`、`visualMap`、`toolbox`、`graphic`，图表正常渲染。

### JSON 与表单

- [ ] 输入非法 JSON，底部显示错误且不更新图表。
- [ ] 点击格式化，JSON 缩进恢复规范。
- [ ] 添加未知字段，切换表单后字段仍存在。
- [ ] 搜索 `axisLabel`，命中字段自动展开对应分区。
- [ ] 使用 `formatter` 模板，预览显示格式化文本且不执行脚本。

### 导入导出

- [ ] 导出项目配置，包含 option 与 table。
- [ ] 导出仅 Option，不含大表格。
- [ ] 导入新格式配置，界面与图表恢复一致。
- [ ] 导入非 `formatVersion: 1` 文件，显示明确拒绝提示。

### Electron

- [ ] `pnpm dev:electron` 启动后可导入数据。
- [ ] Electron 中编辑右侧属性，预览实时更新。
- [ ] Electron 中导出 PNG/SVG/PDF 文件可打开。
- [ ] 生产构建后通过 `file://` 加载资源路径正常。
