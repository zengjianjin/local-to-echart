# 全属性编辑器

## 双模式

右侧顶部可在“表单编辑”和“JSON 编辑”之间切换。

- 表单编辑：按分区显示 schema 已覆盖的字段，适合快速调整常用属性。
- JSON 编辑：基于 CodeMirror 6，支持语法高亮、折叠、错误提示、格式化和完整字段输入。

两种模式共享同一个 option。表单写入会同步到 JSON 草稿；JSON 合法输入会在 250ms 防抖后应用到图表。非法 JSON 只保留在草稿区，不会污染配置状态。

## 分区与布局

右侧面板默认宽 420px，点标题栏的展开按钮变为 560px 并自动切换为双列字段布局。字段卡片压缩为两行（标签 + 控件），路径和说明在鼠标悬停时显示。

分区导航常驻显示，按四组排列：

- 基础：全局样式、数据节点、标题、图例、提示框
- 布局：网格、X 轴、Y 轴、其他坐标轴、坐标轴指示器、工具箱
- 系列：数据系列
- 扩展：数据缩放、视觉映射、图形元素、地理坐标系、时间线、区域选择、未知字段

顶部「快捷」行可一键跳转标题、图例、网格、X 轴和系列，并提供「网格线 开/关」按钮，一次写入 X/Y 轴的 `splitLine.show`。

搜索支持字段名、路径和中文标签。命中结果会自动过滤分区与字段；点击快捷按钮会清空搜索。

## 字段类型

- 文本、数值、颜色：输入框。留空表示删除该字段，让 ECharts 使用自己的默认值。
- 布尔开关：三态。未设置时虚线轨道、圆点居中并标注「默认（未设置）」；点击写入 `false`。已设置后变为普通二态开关，标签旁可「恢复默认」。
- 枚举：下拉框，第一项为「未设置（默认）」。
- 对象：折叠为字段组，子字段路径以数组项或上级对象为基准。
- 数组：卡片列表，支持新增、复制、上移、下移、删除。新增项只写入 schema 中声明的真实默认值。
- 模板：用于 `formatter` 等函数型字段。
- 未知：仅保留和查看，必须通过 JSON 修改。

结构化值（例如 `visualMap.inRange.color`、`brush.toolbox`、`tooltip.padding`、`series.center`、`dataZoom.xAxisIndex`）可直接在输入框中粘贴 `["#4F8CFF", "#22C55E"]`、`[50%, 50%]`、`[0, 1]` 等写法，编辑器会解析为数组；纯数字会写成数字。`series.encode.x/y/itemName/value` 也会把 `2` 或 `[1, 2]` 转成对应的数字或数组。

## 数组编辑

`series`、`xAxis`、`yAxis`、`dataZoom`、`visualMap`、`graphic` 等字段使用数组编辑器。每项使用稳定索引路径，例如 `series[1].itemStyle.color`。series 字段会按当前项的 `type` 过滤专属属性；饼图显示 `encode.itemName` / `encode.value`，柱图、折线图、散点图和热力图显示 `encode.x` / `encode.y`。

注意 `grid.show` 遵循 ECharts 原生语义，只控制直角坐标系的底纹与边框，不控制坐标轴分隔线。分隔线请使用 X/Y 轴的 `splitLine.show`，或工具栏的「网格线」快捷按钮。

## 未知字段

JSON 中新增但 schema 未覆盖的根字段会显示在“未知字段”分区。表单编辑只会修改指定路径，不会重建整棵 option，因此未知字段会被保留。

## 函数型字段

配置必须可序列化，因此不保存 JavaScript 函数。`formatter` 使用如下描述：

```json
{
  "__templateFormatter": {
    "template": "{b}: {c}",
    "preset": "{b}: {c}"
  }
}
```

运行时适配器只会替换 `{a}`、`{b}`、`{c}`、`{d}`、`{value}`、`{name}` 等变量，不会执行脚本。
