# 多语言说明 / Internationalization

本项目使用 `vue-i18n` 提供界面与运行时文案的多语言支持，当前内置简体中文（`zh-CN`）、繁体中文（`zh-TW`）和英文（`en-US`）。渲染进程是翻译核心；Electron 主进程通过最小 preload/IPC 桥同步窗口标题与开发菜单。

## 目录结构

```text
src/i18n/
├── index.ts                 # vue-i18n 实例、locale 读写
├── language.ts              # 系统语言检测、localStorage 读写
├── translate.ts             # 非组件环境使用的 t()
├── schema.ts                # schema 展示文案按 locale 解析
├── electron.ts              # 通知主进程当前语言
├── types.ts                 # Locale 等类型
└── locales/
    ├── zh-CN/               # 简体中文资源（也是 schema 文案的键基准）
    │   ├── common.ts
    │   ├── workspace.ts
    │   ├── data.ts
    │   ├── chart.ts
    │   ├── settings.ts
    │   ├── runtime.ts
    │   ├── electron.ts
    │   └── schema.ts
    ├── zh-TW/               # 繁体中文资源，与 zh-CN 同构
    │   └── ...
    └── en-US/               # 与 zh-CN 同构的英文资源
electron/
├── i18n.cjs                 # 主进程标题与菜单字典
└── preload.cjs              # 只暴露 setLocale 的窄接口
```

## 语言选择行为

1. 首次启动时读取 `navigator.language` / `navigator.languages`：`zh-TW` / `zh-HK` / `zh-Hant` 使用 `zh-TW`，其他 `zh` 前缀使用 `zh-CN`，`en` 前缀使用 `en-US`，其余语言回退到 `zh-CN`。
2. 顶栏语言按钮按「简体 → 繁體 → EN」循环切换，按钮显示下一个目标语言，提示中显示当前语言；选择写入 `localStorage` 的 `echarts-studio-locale`。
3. 下次启动优先读取该键，未设置时才重新检测系统语言。
4. 切换会同步 `<html lang>`、页面标题、页面描述和 Electron 窗口标题/开发菜单。

## 翻译入口

- Vue 模板与组件：`useI18n()` 返回的 `t`，或模板中的 `$t`。
- `utils` / `composables` / 非组件模块：`import { translate } from '@/i18n/translate'`。
- schema 字段展示文案：`translateSchemaText()` 和 `localizeField()` / `localizeSection()`。源 schema 保留中文字符串作为稳定键，`path`、`section`、枚举 `value` 等 ECharts key 不参与翻译。
- 动态文案统一使用插值，例如 `t('data.viewAllRows', { count })`，不在业务代码中拼接面向用户的句子。

## 搜索与字段匹配

`src/schema/registry.ts` 的搜索同时匹配：

- 稳定的 `path` / `section.id`；
- schema 源文案（中文键）；
- 当前语言的展示文案。

因此切换语言后，用简体、繁体或英文关键词搜索字段都应能命中；ECharts option 的写入路径不会因语言变化而改变。

## Electron 侧

- `electron/main.cjs` 维护 `currentLocale`，通过 `ipcMain.on('i18n:set-locale')` 接收渲染进程通知并重建菜单/标题。
- `electron/preload.cjs` 只暴露 `window.electronAPI.setLocale`，保持 `contextIsolation`、`sandbox` 开启且 `nodeIntegration` 关闭。
- 当前没有原生对话框；后续新增时应复用 `electron/i18n.cjs` 的字典。

## 新增语言

以新增 `ja-JP` 为例：

1. 在 `src/i18n/types.ts` 的 `Locale` 联合类型和 `SUPPORTED_LOCALES` 中加入 `ja-JP`。
2. 复制 `src/i18n/locales/en-US/` 为 `src/i18n/locales/ja-JP/`，逐模块翻译；`schema.ts` 的键保持源中文字符串不变，只替换值。
3. 在 `src/i18n/locales/index.ts` 注册新语言，并用 `AppMessages` 约束结构一致。
4. 在 `electron/i18n.cjs` 添加对应字典分支；如需系统语言自动识别，也更新 `detectSystemLocale()`。
5. 在 `WorkspaceShell.vue` 的 `localeOrder` 与 `localeLabels` 中加入新语言；超过三种语言时建议把循环按钮改为下拉选择。
6. 运行 `pnpm typecheck` 与 `pnpm build`，并按 `qa-checklist.md` 做浏览器/Electron 双端验收。

## 范围与限制

- 翻译应用文案，不翻译用户数据：CSV 单元格、sheet 名、用户自定义系列名保持原样。
- `PNG` / `SVG` / `PDF`、`CSV` / `JSON`、`meta.name`、`encode.x`、字体名、模板变量等技术字符串保持不变。
- `app.yaml` / `data.yaml` 是界面快照，不是语言资源源。
- `docs/screenshots/` 中的截图仍是中文界面。新增语言的截图需要在切换语言后重新截取，文件名保持不变，只更新 alt/图注。

## English summary

`vue-i18n` is installed with `zh-CN`, `zh-TW`, and `en-US` resources. The first launch follows the browser/system language (`zh-TW` / `zh-HK` / `zh-Hant` map to Traditional Chinese), then the user's choice is persisted in `localStorage`. The header button cycles through Simplified Chinese, Traditional Chinese, and English. Vue components use `useI18n()`; non-component modules use `translate()`. Schema display text is resolved from source Chinese keys through `translateSchemaText()` so that stable ECharts paths and enum values are never translated. Electron receives locale changes through a narrow preload bridge and rebuilds its title and development menu. To add a language, copy the `en-US` resource folder, register the locale, and provide the matching Electron dictionary.
