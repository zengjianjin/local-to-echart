# 数据绑定

## 数据进入图表

导入的 CSV/TSV 使用 PapaParse 解析，Excel 使用 SheetJS。Excel 含多个工作表时会弹出选择框，用户选定后按表名读取；单工作表文件直接读取首个工作表。

## 表头行

Excel 默认从第 1 行读取字段名。对于「第一行是分组标题、第二行才是字段名」的两行表头，在左侧「Excel 表头行」填 `2` 即可；修改后会立即用缓存的文件重新解析，多工作表文件在工作表选择弹窗里也能改。上方行的横向合并单元格会被识别为分组名，并拼到字段名前面（例如 `中长期合同 / 省内净合同电量`）；重名会自动加序号，避免 ECharts 维度冲突。

解析后生成 `TableData`：

```ts
interface TableData {
  name: string
  columns: string[]
  rows: Array<Array<string | number | boolean | null>>
  inferredTypes: Array<'number' | 'boolean' | 'date' | 'text'>
  rowCount: number
}
```

点击“重新生成”会把当前表格写入：

```json
{
  "dataset": [
    {
      "id": "workspace-dataset",
      "sourceHeader": 1,
      "source": [
        ["月份", "销售额"],
        ["1月", 128.5]
      ]
    }
  ],
  "series": [
    {
      "type": "bar",
      "encode": { "x": 0, "y": [1] }
    }
  ]
}
```

## 字段映射

字段映射完全使用 ECharts 标准字段：

- `dataset.source` 提供数据。
- `dataset.sourceHeader` 表示表头行数：`1` 表示首行为表头，`0` 表示没有表头；它不是从 0 开始的行索引。
- `seriesLayoutBy` 控制按列或按行布局。
- `series.encode` 控制维度到坐标轴、提示框和系列名的映射。
- `series.datasetIndex` 选择数据节点。

## 类目字段

右侧「图表设置 → X 轴 → 轴字段映射」为每个 X 轴选择一个类目字段；切换字段只更新对应系列的 `encode.x`，不重建表格数据，避免数据量大时切换卡顿。若 X 字段同时也是某个系列的数值列，会使用复制维度避免系列丢失。

## 数据配置与系列名称分组

图表设置 → 系列 里是**数据配置数组**，每一项都拥有独立的数值字段、系列名称拼接字段、分组取值、堆叠方式、上限与聚合方式，并生成属于这一项的多个数据系列子项；多个配置共存，图表里会同时显示所有配置生成的系列。每项配置内部都有「批量配置本组系列」面板，只修改当前配置生成的系列；它覆盖通用与轴控制（系列类型、X/Y 轴索引、层级、交互）、柱图、折线/散点、图形样式、标签、线条/面积与饼图字段，留空的字段不会被修改，应用后会作为该配置的默认值保存，重新生成仍生效。左侧数据节点面板只保留「重新生成 / 清空」，不再提供与右侧不匹配的单字段快速添加。

如果同一类目下有多行数据（例如每个日期有 96 个时段），选择**数值字段**和**名称拼接字段**（如「时段」）会把行按名称拆成多个系列，每个系列名是「拼接后的值 · 数值字段名」（例如 `2026-06-01 · 实际用电量`）；tooltip 里既能看出分组也能看出数值字段。

堆叠方式有多种：不堆叠（并列）、累加堆叠、百分比堆叠（同组数值按类目归一到 100）、同号堆叠 `stackStrategy: samesign`、全值堆叠 `stackStrategy: all`。每项配置写入独立的派生 dataset：`workspace-series-dataset-<配置序号>`，系列 id 为 `workspace-series-group-<配置序号>-<系列序号>`，通过 `datasetIndex` 与 `encode.x/y` 指向；`stack` 按配置分组，不会把不同数据配置混堆在一起。

名称字段的可选值过多时会生成大量系列，界面提供「参与分组的取值」chips，**默认只选前 4 个取值**（可点「全选」），同时提供「最多系列数」（默认 24）和「最多类目数」（默认 100）两道保险，以及同组同值的聚合方式（求和 / 平均 / 首条值）。推荐把 **X 字段设为日期、名称字段只勾时段**。

数字文本会先用 `src/utils/numberParse.ts` 的 `toNumber` 清洗：去掉千分位逗号、百分号、`¥`/`$` 等货币符号和空格，支持 `(1,024)` 表示负数；清洗后能转成数字的字符串会按数值列处理，日期等非数值文本不受影响。

项目不再维护 `categoryField`、`valueField`、`stackField` 或 `aggregate` 等自定义字段。

## 类型转换

CSV 文本会按推断类型转换为数字或布尔值。首行为表头，后续行为数据。Excel 日期会转成 `YYYY-MM-DD` 字符串。空值保存为 `null`。

## 数据预览

左侧列表是速览，只显示前 12 行与前 5 列，表头带字段类型标识。点击「全量」打开弹窗后可查看所有行列、按任意单元格搜索，并通过滚动分批加载更多数据（每批 500 行）。弹窗支持 `Esc` 关闭。

## 导出策略

- “项目配置”导出包含 option 与当前 table。
- “仅 Option”导出不包含大表格数据；再次导入时需要重新导入数据文件。
- “导入配置”可恢复此前导出的项目配置，旧 `formatVersion` 会被拒绝。
- PNG / SVG / PDF 支持分辨率选择：跟随预览、1920×1080、2560×1440、3840×2160 或自定义宽高。图片一律使用深色背景 `#0F172A`，与当前界面主题无关。
